# Global Registry

Global Registry is a provider-neutral desired-state registry for resources, provider
bindings, operations, observations, drift, audit events, outbox records, and exports. It
records registry state; it does not call provider APIs or store provider credential values.

## Boundary

- D1 is the authoritative store for registry state, history, audit events, outbox records, locks, and export status.
- R2 stores completed exports and archived observations.
- Queue delivery is at-least-once and is driven by the persisted D1 outbox.
- Provider credentials are represented only by uppercase references such as `PROVIDER_CREDENTIAL`; a reference is not a secret.
- Provider configuration and mappings are bounded non-secret JSON. Global Registry preserves them for external adapters but does not interpret provider-specific fields or call provider APIs.
- Production access requires Cloudflare Access and an active Actor mapping. Local authentication is development-only and loopback-only.

The Product repository contains no environment-specific account, hostname, resource, Access,
or credential values. The private Instance repository owns release pins and environment
desired state. See [Deployment](docs/deployment.md) for the manifest contract and CLI.

## Requirements

The repository pins Node.js `24.18.0` and pnpm `11.12.0` through mise. Install Chromium
before browser-backed local-auth checks.

## Local start

Copy `.dev.vars.example` to `.dev.vars` and set `LOCAL_AUTH_SECRET` to a fresh value
generated by `openssl rand -hex 32`. Keep `.dev.vars` private.

```sh
mise install --locked
pnpm install --frozen-lockfile
mise run migrate-local
mise run dev
```

After applying pending migrations, create the first local admin:

```sh
mise run bootstrap-admin -- \
  --database DB \
  --identity access:<subject> \
  --display-name "Registry Administrator"
```

The command defaults to local D1 and refuses to run if an admin Actor already exists. The
repository has no seed or legacy import command.

## Verification

```sh
pnpm browser:install
mise run check
mise run smoke
pnpm check:local-auth
pnpm deployment:validate-example
```
